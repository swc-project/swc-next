# SWC regular expression parser

This crate is a validation-focused fork of
[`oxc_regular_expression` 0.137.0](https://github.com/oxc-project/oxc/tree/oxc_regular_expression-v0.137.0/crates/oxc_regular_expression),
used under the Apache-2.0 license. It uses `swc_next_allocator` for the parsed
regular expression AST.
