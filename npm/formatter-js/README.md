# @swc-next/formatter-js

JavaScript, JSX, TypeScript, and TSX formatting document production for SWC Next, with native and WebAssembly bindings for Node.js.

**Experimental and unstable.** This package is an internal dependency of the [Prettier plugin](../formatter-prettier-plugin). Its option and document protocols require matching package versions.

Use the Prettier plugin to format source text. See the [Rust formatter](../../crates/swc_formatter_js) for source and AST formatting APIs.
