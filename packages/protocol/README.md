# `@swc-next/protocol`

Shared JavaScript source for SWC Next's internal native and WebAssembly
protocols. Includes AST encoders and decoders, parser and generator
configuration encoders, source transport, and transform options and output.

This private workspace package is bundled into each API by Rslib. It is not
published or required at runtime. Import the specific protocol entry point so
each API includes only the protocols it uses.

```js
import { encodeParserConfig } from "@swc-next/protocol/parser";
import { decode } from "@swc-next/protocol/ast/decode";
```

APIs and wire formats do not follow semantic versioning. JavaScript and
native/Wasm code must use matching versions. Source, AST, and transform option
encoders reuse scratch storage; consume borrowed buffers before calling the
same encoder again. AST and transform option encoding are not reentrant.

## Building and testing

From the workspace root, build the API JavaScript entry points with
`pnpm build:js`. Rslib bundles each API's `src-js/index.js` into `dist/index.js`,
copying binding loaders and declarations into each API's `dist` directory.
`pnpm test`, `pnpm test:wasm`, and `pnpm test:codec` cover the protocols through
the core API.

AST codecs are generated by `cargo run -p ast_tools`. Change the AST
declarations or generators rather than generated files.
