# `@swc-next/protocol`

Shared JavaScript source for SWC Next's internal native and WebAssembly protocols. Includes AST and document encoders, parser and generator configuration encoders, source transport, transform options and output, and formatter configuration and results.

This private workspace package is bundled into each API by Rslib. It is not published or required at runtime. Import the specific protocol entry point so each API includes only the protocols it uses.

```js
import { encodeParserConfig } from "@swc-next/protocol/parser";
import { encodeFormatterConfig } from "@swc-next/protocol/formatter";
import { decode } from "@swc-next/protocol/ast/decode";
```

APIs and wire formats do not follow semantic versioning. JavaScript and native/Wasm code must use matching versions. Source, AST, and transform option encoders reuse scratch storage; consume borrowed buffers before calling the same encoder again. AST and transform option encoding are not reentrant. Formatter and document encoders return owned buffers. Conversion from SWCD documents to Prettier Docs belongs to the Prettier plugin.

## Testing

From the workspace root, `pnpm build:js` builds the API JavaScript entry points. `pnpm test` and `pnpm test:wasm` cover the protocols through the core and formatter APIs; `pnpm test:codec` covers AST codecs.

AST codecs are generated by `cargo run -p ast_tools`. Change the AST declarations or generators rather than generated files.
