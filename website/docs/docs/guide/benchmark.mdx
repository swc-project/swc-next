## JS parse + walk

Each iteration parses a fresh AST and counts `Identifier` nodes using SWC Next's `walk`, SWC's `Visitor`, or Babel's `traverse` with `noScope: true`. No scope analysis, AST edits, or comment traversal is requested. Counts follow each parser's AST representation and can differ, for example for shorthand properties.

This group uses JavaScript inputs because SWC's JS Visitor does not implement TypeScript type traversal.
