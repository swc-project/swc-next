# AST interop

Advanced interfaces for moving AST data across the Rust and JavaScript boundary.

## Packages

- @swc-next/encoder and @swc-next/decoder.
- Pass AstMeta to preserve language and source type.

## Version matching

- Use exact matching codec and binding versions.
- The binary transfer format is internal and versioned with the Rust crates.
