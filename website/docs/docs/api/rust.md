# Rust API

Use component rustdoc for function signatures, options, and AST contracts.

## Compiler components

- Allocator, AST, parser, semantic analysis, transformer, and code generator.
- Minifier, type strip, isolated declarations, and regular expressions.

## API status

- The API is experimental and currently has known AST handle soundness issues.
