# Methodology

Make performance claims reproducible and comparable.

## Environment

- Record hardware, runtime, versions, commits, input files, and options.

## Measurement

- Document warmup, repetitions, GC policy, and whether the full AST is read.
- Keep instruction counts separate from wall-clock results.
