## One small program. A place to start.

Install the core package to parse and print your first program.

```sh
npm install @swc-next/core
```

```js title="index.mjs"
import { parseSync, printSync } from "@swc-next/core";

const { program, diagnostics, meta } = parseSync("const answer = 42;");
console.log(diagnostics);
console.log(printSync(program, {}, meta).code);
```

## A different foundation

A compact, flat AST sits at the center of SWC Next. The JavaScript API exposes an AST compatible with [ESTree](https://github.com/estree/estree), with TypeScript and JSX nodes following typescript-eslint's AST format.

[Explore the architecture](/architecture/flat-ast) or [see Publish Results](/guide/publish-results).
