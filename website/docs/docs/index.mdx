## One small program. A place to start.

Install the core package to parse and print your first program.

```sh
npm install @swc-next/core
```

```js title="index.mjs"
import { parseSync, printSync } from "@swc-next/core";

const { program, diagnostics, meta } = parseSync("const answer = 42;");
console.log(diagnostics);
console.log(printSync(program, {}, meta).code);
```

## A different foundation

A compact, flat AST sits at the center of SWC Next. Rust components share that representation, while JavaScript receives an ESTree-based tree you can inspect and edit.

[Explore the architecture](/resources/architecture/flat-ast) or [see the benchmarks](/benchmarks/).
